# GiveFlow 🎁

> A modern online giveaway platform that simplifies the creation, management, and participation of digital giveaway campaigns.

GiveFlow is a frontend-first giveaway management platform designed to provide a seamless and transparent experience for both giveaway organizers and participants.

The platform allows users to discover active campaigns, explore giveaway details, monitor campaign status, participate in contests, and transparently select winners through an interactive interface.

Built as a Minimum Viable Product (MVP), GiveFlow prioritizes user experience, accessibility, responsiveness, and modern design principles.

## 🚀 Installation

### Clone the repository

```bash
git clone https://github.com/Egcarson/giveflow.git
```

### Navigate to the project directory

```bash
cd giveflow
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Open the application

```text
http://localhost:3000
```

## 🎨 Design Philosophy

GiveFlow was built around four core principles:

- Simplicity
- Transparency
- Accessibility
- User Engagement

The design combines modern SaaS-inspired interfaces with subtle animations, clean typography, responsive layouts, and interactive user experiences.

## ⚠️ Current Limitations

This version is a frontend MVP.

Current limitations include:

- No authentication system
- No database integration
- No persistent data storage
- Giveaway creation is currently UI-based
